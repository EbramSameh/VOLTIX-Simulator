VOLTIX SIMULATOR is an online circuit simulator for Arduino, ESP32 and Raspberry Pi projects. Place resistors, LEDs, capacitors, inductors, motors, motor drivers and dozens of sensors, bend wires like in Wokwi or Tinkercad, write code with colour and autocomplete, and look at your circuit in 3D.
Honest scope: the simulator is a teaching model, the browser vision demo is simple pixel analysis, and nothing here runs on a Raspberry Pi until you run the generated commands on one.

About VOLTIX
VOLTIX SIMULATOR is a browser electronics lab: a circuit editor with a nodal-analysis solver, an Arduino-style code runner, a virtual Wi-Fi gateway, and a Raspberry Pi and AI preparation area.
Cloud features and scope
Google sign-in, cloud projects, and public project links require the VOLTIX Firebase project to be configured, with Authentication providers and Firestore security rules enabled. Browser-local saving remains available. The simulator still does not provide a real ESP32 network bridge or run neural networks in the browser.
Other development areas
A Raspberry Pi companion service with device pairing, additional circuit models such as MOSFETs and op-amps, AC analysis, and broader 3D component coverage remain future development work.
